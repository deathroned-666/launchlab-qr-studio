Privacy Policy

LaunchLab QR Studio is designed as a browser-based utility. The text, links, Wi-Fi details, and contact information you enter are used to create a QR code in your browser.

Information you enter

The current static version of this tool does not require an account and does not intentionally store QR code contents on a server. If you download a QR code, the file is created on your device.

Analytics and advertising

LaunchLab QR Studio does not currently use analytics, advertising scripts, tracking pixels, or account sign-ins. If analytics or advertising are added later, this page will be updated first to describe the providers used, the data collected, cookie behavior, and opt-out options.

Payments

Paid subscriptions on the pricing page are processed by PayPal. PayPal may collect payment details, account information, device information, and transaction data according to its own privacy policy. LaunchLab QR Studio does not receive or store full card details.

Third-party code

The QR code library is loaded from jsDelivr, a public CDN. jsDelivr may receive standard request information such as IP address, browser type, and requested file URL when the library file loads.

Contact

Use the contact page or email launchlab9@gmail.com for privacy questions or site feedback.

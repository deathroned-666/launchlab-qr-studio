Privacy Policy

LaunchLab QR Studio is designed as a browser-based utility. The text, links, Wi-Fi details, and contact information you enter are used to create a QR code in your browser.

Information you enter

The current static version of this tool does not require an account and does not intentionally store QR code contents on a server. If you download a QR code, the file is created on your device.

Analytics and advertising

If analytics or advertising are added later, this page should be updated to describe the providers used, the data collected, cookie behavior, and opt-out options.

Third-party code

The QR code library may be loaded from a public CDN. The CDN provider may receive standard request information such as IP address, browser type, and requested file URL.

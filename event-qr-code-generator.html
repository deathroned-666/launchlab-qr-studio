Event QR Code Generator

Create an event QR code for posters, invitations, workshops, school events, meetups, and conference signs. Scanners can save the event details to a calendar app when their device supports calendar QR content.

Create an event QR code

Good event QR content

  • Short event title.
  • Exact location or venue name.
  • Start and end time.
  • Brief details such as RSVP note, room number, or parking reminder.

Poster advice

For posters, use a larger QR code than you would on a business card. A 4 inch code is a safer starting point for wall signs viewed from several feet away.
